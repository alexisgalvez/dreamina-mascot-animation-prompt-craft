# Dreamina 3D Character & Mascot Animation Prompt Craft

Client-side web app for converting 2D vector / illustration mascot characters into continuous 30-second 3D AI video animations for Dreamina Seedance 2.5 and Seedream 5.0.

## Files:
- `index.html`: Web interface with mascot reference slot, 3D style selector, environment picker, and 3-beat storyboard timeline.
- `style.css`: Modern glassmorphic theme with neon accents and responsive layout.
- `app.js`: Prompt compiler that anchors character identity to `@Image 1` and builds chronological video prompts.
- `PROMPT_ENGINE.md`: Prompt tokens and identity lock formulas for Seedance 2.5.
- `DESIGN.md`: CSS design tokens and component specs.
- `APP_SPEC.md`: Architecture and deployment guide.
